CHECKPOINT 7 - benchmark, ablations, statistics, failure taxonomy, unseen datasets   (2026-10-13)

HEADLINE
  The full system (A_full) reaches a normalized test score of 0.84 (95% CI 0.51 to 1.14, bootstrap over 12 development
  datasets; median over datasets 0.96). It beats the default random forest on 12/12 datasets (sign test p < 0.001) and
  default LightGBM on 11/12 (p = 0.006), and it ties the 60-second FLAML baseline: 6 won, 6 lost (p = 1.0). Strategy
  escalation is the only ablation with a significant effect (+0.62 normalized points, p = 0.034) for 1.13x the cost.
  Tools, memory and the multi-agent split did NOT show a significant benefit. On the 3 never-touched datasets the
  system scores 0.83 (CI 0.44 to 1.05; 9 runs, none failed) and beats the random forest and LightGBM on 3/3 datasets
  and FLAML on 2/3. None of the 750 benchmark attempts was flagged by the integrity monitor.

SCOPE AND WHAT IS NOT CLAIMED
  * 12 development datasets x 3 seeds x 5 variants = 180 runs, plus 9 unseen runs; 2,693 model calls in total.
    Normalized score: 0 = default random forest (B0), 1 = the better of default LightGBM / FLAML, on the harness test split.
  * Variant F (larger-model swap) was NOT run: gemini-3.8-flash allows about 20 calls per day and one run needs about 22.
  * Two lanes, because the free quota is per model: credit_g, credit_approval, sick, churn, bank_marketing, car, diamonds
    ran on gemini-3.5-flash-lite; eucalyptus, letter, abalone, moneyball, california_housing on gemini-3.1-flash-lite.
    The dataset decides the lane, so every variant uses the same model on a given dataset and paired comparisons are
    not confounded by the model; absolute scores and wall-clock times still mix the two models.
  * 3 seeds per dataset cannot support per-dataset significance claims; tests are over datasets (n = 12).
  * The normalized score is unstable when the baselines nearly tie (abalone 0.54 to 4.03 across variants, eucalyptus
    -2.23 to 2.02); win rates against the baselines are the more reliable summary. Failed runs count as the worst score.
  * The taxonomy labels on the sheet were drafted by Claude, not by an independent human (results/taxonomy/LABELLED_BY.txt);
    kappa is the judge's agreement with them.

READING THE ABLATIONS
  * Escalation helps: against E_no_memory, which differs only by allowing strategy changes, the variant without it is worse
    on 9 of 12 datasets (credit_approval, sick and eucalyptus fail badly: -2.02, -1.76, -1.40) and costs about 0.9x per run
    ($0.0063 vs $0.0071).
  * Removing the tools did not hurt (+0.39, p = 0.62) and was cheaper ($0.0060 vs $0.0071 per run); a single ReAct agent was
    slightly better than the graph (+0.32, p = 0.15) but used 6.0 attempts per run against 3.3.
  * Memory (A vs E) is +0.16 (p = 0.85) at 1.7x the tokens: no evidence that it helps, consistent with the Phase 5 pilot.
  * Cost per point of normalized score: D 0.0059, C 0.0087, A 0.0105, E 0.0113 USD-equivalent; B 0.84 (its score is near 0).
